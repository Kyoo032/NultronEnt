# DPSBuddy Enterprise

Release notes for **DPSBuddy Enterprise**, the hosted multi-user edition of DPSBuddy by DPS. This repository publishes releases only; it contains no source code.

## What it is

DPSBuddy Enterprise is DPSBuddy run as a web app for a whole team. Your organisation signs in from the browser, and each person works at their own desk: chat, documents, research, finance, data and the other work modes, with the organisation's knowledge base alongside. There is nothing to install. DPS hosts and updates it.

## Get access

DPSBuddy Enterprise is sold per user. To set up your organisation, contact DPS; your team receives its sign-in details during onboarding.

## Releases

Each update to the hosted service is published here as a [GitHub Release](https://github.com/Kyoo032/DPSBuddy-Ent/releases) with release notes describing what changed. Updates reach your organisation automatically; there is nothing to download.
